## 4. 操作指南

|   Player行为   |           硬件操作           |                  备注                  |
| :------------: | :--------------------------: | :------------------------------------: |
|    调整视线    |        调整头显的朝向        |                                        |
| 与用户界面交互 | 手柄射线对准组件并按下扳机键 |        部分界面使用其他手柄按键        |
|      移动      |         跑步机上移动         |           也可使用左手柄摇杆           |
|      转向      |         跑步机上转向         |                                        |
|      跳跃      |         跑步机上跳跃         |           也可按下右手柄A键            |
|      开火      |         右手柄扳机键         |                                        |
|      装弹      |          右手柄B键           |       也可在子弹为0时按下开火键        |
|      翻滚      |         左手柄扳机键         |                                        |
|      换枪      |         右手柄抓握键         |                                        |
| 左手显示屏开关 |         左手柄抓握键         |                                        |
|  录制语音命令  |          左手柄X键           | 按一次开始录制，再按结束录制并发送命令 |
|    暂停训练    |       左手柄摇杆键按下       |                                        |
|    调试模式    |       右手柄摇杆键按下       |                                        |
|    唤起菜单    |          左手柄Y键           |                                        |
